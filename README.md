# .notchdeck

нативная панель для чёлки Mac: музыка, история буфера обмена, полка файлов и таймер.

SwiftUI и AppKit, macOS 14+. размер камеры и положение панели берутся из геометрии подключённого экрана. на дисплее без чёлки используется отдельная компактная панель.

## разработка

```sh
swift build
swift test
```
